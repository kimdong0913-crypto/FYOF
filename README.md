# FYOF (Find Your Outfit)

> **AI 가상 피팅과 커뮤니티 데이터로 코디를 알려 주는 스타일 정보 서비스**

"이 옷, 내 옷장 속 바지랑 어울릴까?" "남들이 보기에 이상하지 않을까?"
옷을 고를 때 감에만 의존하던 코디 결정을, **사람들이 실제로 입고 추천한 데이터**와 **AI 가상 피팅**으로 도와주는 웹 서비스입니다.

- 진행 기간: 2026. 10. 06 ~ 2026. 10. 30 (1차 발표 10/13, 이후 보완)
- 분야: 웹, AI·데이터

---

## 1. 배경과 목표

**배경**
- 새 옷을 살 때마다 기존 옷과 어울릴지 고민하지만, 지금은 각자의 감에만 의존해서 옷을 사 놓고 안 입거나 반품하는 일이 생깁니다.

**목표**
- 옷장 등록, 커뮤니티 코디 통계(%), AI 가상 피팅을 갖춘 웹 서비스를 만들고 클라우드에 배포해 시연합니다.

**대상 사용자**
- 옷을 살 때 기존 옷과 어울릴지 고민하는 20대 대학생과 패션 초보자
- 코디 경험을 나누고 싶은 사용자

## 2. 주요 기능

| No | 기능 | 내용 | 상태 |
|---|---|---|---|
| 1 | 나만의 옷장 | 가진 아이템을 등록하고, 내 아이템으로 입을 수 있는 인기 코디와 피팅 결과를 저장 | 완료 (사진 자동 등록은 예정) |
| 2 | 코디 통계 (STYLE DATA) | 코디를 5칸(아우터·상의·하의·신발·액세서리) + 색 + 핏으로 올리고 추천하면, 아이템마다 많이 입는 색·아이템 비율(%)을 실제 데이터로 표시. 성별·연령 필터 | 완료 |
| 3 | AI 가상 피팅 | **사진 피팅**: 내 사진에 옷을 합성 (FASHN VTON 1.5)<br>**실시간 피팅**: 카메라 영상에 상의·아우터를 실시간으로 입힘 (Decart API, 1회 30초) | 완료 |
| 4 | 구매처 링크 태그 | 코디 사진 위 위치에 구매처 링크를 최대 5개까지 표시 | 완료 |
| 5 | 커뮤니티 | 코디 사진 업로드, 추천, 댓글, 신고(3회 누적 시 숨김), 욕설 필터, 프로필 피드, 활동 등급·배지, 주간 순위 | 완료 |
| 6 | 스타일 가이드 | 아이템 73종마다 실사 사진, 핏 종류별 그림, 많이 입는 색, 입는 팁 | 완료 |
| 7 | 체형 핏 추천 | 내 프로필에 키·몸무게·체형을 입력하면 아이템별로 어울리는 핏을 추천 (본인만 보임) | 완료 (기본) |

### 차별점
- 기존 쇼핑몰의 코디 추천은 판매자가 정한 것이지만, FYOF는 **실제 사용자들이 고르고 추천한 데이터(%)**를 근거로 보여 줍니다.
- 새 옷 하나만 보는 게 아니라 **내 옷장 속 아이템과 함께** 보고, **AI 피팅으로 입은 모습**까지 확인할 수 있습니다.
- 커뮤니티 게시물의 "이 코디 입어보기"를 누르면 **그 사람의 코디를 카메라로 바로 입어 볼 수 있습니다.**

## 3. 기술 스택과 구조

| 부분 | 기술 |
|---|---|
| 프론트엔드 | React, TypeScript, Vite, TanStack Router (Lovable로 만든 초안을 직접 수정) |
| 백엔드 | Java 21, Spring Boot 4 (REST API), Gradle |
| DB | MySQL 8.4 (1차는 Google Cloud SQL, 지금은 로컬) |
| AI | Python FastAPI + PyTorch, [FASHN VTON 1.5](https://github.com/fashn-AI/fashn-vton-1.5) (사진 피팅) / Decart Lucy VTON API (실시간 피팅) |
| 인프라 | Google Cloud Platform (VM, Cloud SQL), Git·GitHub |

```
브라우저 ─ 프론트(React, :8080) ─ 백엔드(Spring Boot, :8081) ─┬─ MySQL           회원·코디·추천·댓글
                                                              ├─ AI 서버(FastAPI, :8000)   사진 피팅
                                                              └─ Decart API (임시 토큰 발급)  실시간 피팅
```

| 폴더 | 내용 |
|---|---|
| `frontend/` | 웹 화면 |
| `backend-demo/` | API 서버 |
| `ai/ai-service/` | 사진 피팅 추론 서버 (`server.py`) |
| `ai/fashn-vton-1.5/` | 피팅 모델 코드 |

> 각 폴더의 README.md에 파일별 역할을 적어 뒀어요.
> 폴더 이름(`backend-demo`, `fashn-vton-1.5`)은 코드 안에서 경로로 쓰고 있어서 원래대로 뒀다.

## 5. 문제와 해결

| 문제 | 해결 |
|---|---|
| Java 서버가 AI 서버로 사진을 보내면 422 오류 | Java HttpClient의 HTTP/2 업그레이드 시도가 원인 → HTTP/1.1로 고정 |
| GPU 없는 서버에서 피팅 1회가 7분 넘게 걸림 | 작업 번호를 먼저 돌려주고 3초마다 확인하는 비동기(폴링) 방식, 계산 단계 20 → 10 |
| 클라우드 요금이 계속 나감 | 코드 백업 후 서버 정리, 로컬 실행 환경과 실행 스크립트(`start-local.bat`) 마련 |
| 실시간 피팅은 사용 시간(초)만큼 요금 | 서버가 30초짜리 임시 토큰만 발급, 1인 하루 10회 제한, API 키는 깃에 안 올리는 설정 파일에만 보관 |

## 6. 앞으로 할 것

- GCP에 다시 배포하고 https 적용 (휴대폰에서도 카메라 피팅 가능하게)

## 7. 실행 방법

**필요한 것**: Node.js, JDK 21, MySQL 8 (사진 피팅까지 쓰려면 Python)

**1. 설정 파일 2개 만들기** (비밀번호가 들어가서 저장소에는 없어요)

| 파일 | 내용 |
|---|---|
| `frontend/.env` | `VITE_API_URL=http://localhost:8081` |
| `backend-demo/db.properties` | DB 주소·비밀번호. `db.properties.example`을 복사해서 채우기 (실시간 피팅을 쓰려면 `decart.api-key`도) |

**2. 실행**

| 순서 | 할 일 |
|---|---|
| ① | `frontend` 폴더에서 `npm install` (처음 한 번) |
| ② | `start-local.bat` 더블클릭 → DB, 서버, 화면이 켜지고 브라우저가 열려요 |
| ③ | 끌 때는 `stop-local.bat` 더블클릭 |

> 사진 AI 피팅은 `ai/` 서버를 따로 켜야 해요 (`ai/README.md` 참고). 꺼져 있으면 사진 피팅 버튼만 "사용할 수 없음"으로 나오고 나머지는 그대로 동작해요.
